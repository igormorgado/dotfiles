# Memory

- Store all cloned repositories and source code downloaded from the internet under `~/src`.
- Install skills under `~/.agents/skills` unless a skill requires a specific location.
- When writing documents, avoid em dashes, double hyphens, and other phrasing or punctuation that reads like AI-generated text. Use natural, human-sounding prose.
- For research tasks, read `~/.agents/self-improvement/private/RESEARCH_LOCATIONS.md` if it exists.
